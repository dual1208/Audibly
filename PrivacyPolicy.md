# Privacy Policy

Effective date: 07/21/2026

Audibly Audiobook Player (hereinafter referred to as the "Service").

This fork is designed for local, self-maintained use.

## Information Collection And Use

The app does not collect or transmit telemetry, analytics, diagnostics, crash
reports, usage events, or personal data. Operational messages are written only
to the local application log.

## Use of Data

Local library metadata, playback position, and settings are used only to provide
the player features on this computer.

## Transfer Of Data

The app has no background network client and no vendor backend. Links on the
settings page open only when the user explicitly selects them.

This policy is maintained with the fork source. There is no remote policy or
notification service.
